Source directories:
`platform/icons/src/toolwindows/`, `platform/icons/src/nodes/`, and
`platform/icons/src/fileTypes/`.

Some JavaFX controls reproduce the SVG geometry with JavaFX shapes
because JavaFX `ImageView` does not decode SVG resources directly. The original
SVG files remain packaged alongside the application for source and license
traceability.
